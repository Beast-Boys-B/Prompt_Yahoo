# Yahoo_Prompt

> 누구나 쉽게 AI를 활용할 수 있도록 — 프롬프트 작성 도우미

## 문제 정의

AI 사용자층은 다양한 연령대로 계속 늘고 있지만, AI 비전공자가 작성한 프롬프트는 의도한 산출물을 뽑아내지 못하는 경우가 많습니다. 특히 40대 이상 고령층에서는 프롬프트 입력 자체를 어려워하는 경우가 흔합니다.

현재 이 문제의 해법은 사실상 두 가지뿐입니다.
1. 원하는 답이 나올 때까지 AI와 계속 씨름하기
2. 본인이 프롬프트 엔지니어링을 따로 공부해서 활용하기

**Yahoo_Prompt**는 이 사이의 빈 자리를 채우는 도구입니다. 사용자가 자연어로 편하게 입력하면, 규칙 기반으로 신호를 추출해 AI가 더 잘 알아듣는 프롬프트로 자동 정리해줍니다.

## 타겟 사용자

ChatGPT·Gemini 등 범용 AI를 업무·일상에 활용하려는, 아직 프롬프트 작성에 익숙하지 않은 사용자 (특히 40대 이상, 비전공자)

## 핵심 방향

- **규칙 기반**: 자연어 입력 → 키워드 매칭으로 신호 추출 → 지정 템플릿에 매핑. 구현 안정성을 최우선으로 함.
- **투명한 자동화**: 추출된 신호는 조용히 자동 적용되지 않고, 토글/선택 UI에 "미리 선택된 상태"로만 반영됩니다. 사용자는 항상 결과를 확인하고 직접 수정할 수 있습니다.
- **1차 목표**: 웹페이지 → 이후 Chrome 확장 프로그램(오버레이 형태)으로 확장 예정

## 처리 흐름

```
템플릿 선택 → 자연어 입력 → 신호 추출 → 토글 사전 선택
→ 사용자 확인/수정 → 프롬프트 생성 → 결과 확인 → 완료
```

결과 확인 단계에서 "아니오"를 선택해도 자연어를 다시 쓸 필요 없이, 그 화면 안에서 토글만 바로 고쳐 재생성할 수 있습니다.

## 카테고리 (4개, 팀원별 분담)

| 카테고리 | 설명 | 담당 |
|---|---|---|
| 작성 | 이메일·회의록·보고서·기획서 | |
| 개인상담 | 고민·감정·인간관계 조언 | |
| 의료질문/문진 | 증상 확인·진료 준비 | |
| 여행계획 | 일정·코스 짜기 | |

각 카테고리의 전용 축·키워드 사전 스키마는 [`/schemas`](./schemas) 폴더를 참고하세요. 스키마 작성 방법은 [`CONTRIBUTING.md`](./CONTRIBUTING.md)에 정리되어 있습니다.

## 카테고리 설정 스키마 (요약)

```
카테고리 설정 = {
  이름,
  전용_축: [ {축_이름, 좌/우(또는 3택 이상), 키워드사전, 기본값}, ... ],
  고정_안내문구: (있으면 텍스트, 없으면 null)
}
```

카테고리가 몇 개든, 어떤 축을 갖든 이 스키마 형식만 지키면 신호 추출 엔진 코드를 건드리지 않고 확장할 수 있습니다.
